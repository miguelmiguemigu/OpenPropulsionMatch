How to use it

      
    
        
  1. Plane & settings – enter your airframe (wing area, CLmax, CD0, empty mass, drag articles, cruise speed). Skip this if you only want propulsion numbers.
    2. 
        
  2. Components – tick the motors, props, ESCs and batteries to try. Add your own (forms, prop files, tunnel logs).
    3. 
        
  3. Search – choose Best flight score (uses the plane) or Propulsion only, set the current cap (your ESC limit, e.g. 80 A) and press Run search.
    4. 
        
  4. Click any result row to see it in detail in One combination.
    5. 
      

      
Reading the results

      
    
        
  • Static / @10 m/s – thrust in grams-force at standstill and at 10 m/s, full throttle, fresh pack.
    • 
        
  • Net – mean thrust 0–12 m/s minus the weight of motor + prop + ESC + battery.
    • 
        
  • Payload / score – heaviest takeoff that still lifts off in the takeoff limit, climbs and finishes the mission on 80 % of the pack; score = 1.25 × payload (lb) × drag articles.
    • 
        
  • Peak A / Motor A – highest battery current and highest motor (winding) current. At part throttle the motor carries more current than the battery: I_motor = I_batt / throttle.
    • 
        
  • Warnings: needs current limit = only works with the ESC current limit set (the reason says which rating sets it); Rm/I0 estimated = motor from the rcplanes list, check its datasheet.
    • 
      

      
Good to know

      
    
        
  • Everything runs in your browser – nothing is sent anywhere. Edits last until you reload; use Download data folder to keep them.
    • 
        
  • Accuracy is about ±5–10 % until checked on a thrust stand. Differences under ~2 % are a tie.
    • 
        
  • Model: T = Ct·ρ·n²·D⁴, P = Cp·ρ·n³·D⁵, I_motor = Q/Kt + I0, I_batt = throttle·I_motor, V_batt = Voc − I_batt·(R_pack + R_wiring), throttle·V_batt = RPM/Kv + I_motor·(Rm + R_ESC), solved for the RPM where motor torque = prop torque.
    • 
        
  • Current limit (cap mode): the ESC lowers the throttle so the motor current stays within the motor and ESC rating and the battery current within the pack rating and the battery current cap.
    • 
        
  • Prop data are scaled to real bench tests (APC 12x6E): a torque factor and a thrust factor that depends on the blade tip speed. The bench tests are 2-blade, so 3/4-blade props are unverified – tick 2-blade props only to leave them out. Prop RPM limits follow APC (150,000 / diameter for thin-electric props).
    • 
        
  • Same calculator as propcalc.py – see README.md and GUIDE.md in the folder for all details.
